# BetBattle — Фонбет vs Винлайн (Редакция 2026)

Современный адаптивный веб-лендинг для детального независимого сравнения двух ведущих букмекерских контор России: **Фонбет** (Fonbet) и **Винлайн** (Winline).

🌐 **GitHub Pages (Live Demo):** [https://gl1stodrist.github.io/fonbet-vs-winline/](https://gl1stodrist.github.io/fonbet-vs-winline/)

---

## ⚡ Особенности проекта

- **Полная автономность (Standalone):** Все шрифты (гарнитура Manrope, лицензия SIL Open Font License 1.1), стили, логика и векторная SVG-графика встроены непосредственно в один файл `index.html`. Сайт загружается мгновенно без внешних сетевых зависимостей и CDN.
- **Интерактивное сравнение:** Таблица сравнения по 14 ключевым параметрам с возможностью динамической фильтрации (Все параметры, Бонусы, Линия и ставки, Сервис).
- **Разбор коэффициентов и маржи:** Наглядные таблицы маржинальности по популярным видам спорта (футбол, хоккей, баскетбол, теннис, киберспорт) и карточки с примерами Live-интерфейсов.
- **Интерактивный FAQ и отзывы:** Аккордеон с частыми вопросами (вейджеры, фрибеты, сроки выплат, безопасность) и блок отзывов реальных игроков.
- **Мобильная адаптивность и Accessibility:** Тщательно продуманный UI с адаптивной версткой под смартфоны, планшеты и десктопы, поддержка навигации с клавиатуры и доступности для скринридеров (`aria-*`).

## ⚙️ Настройка партнёрских ссылок

В нижней части файла `index.html` в теге `<script>` расположен конфигурационный объект `AFFILIATE_CONFIG`:

```javascript
const AFFILIATE_CONFIG = Object.freeze({
  fonbet_registration_url: '%%FONBET_URL%%',
  winline_registration_url: '%%WINLINE_URL%%',
  banner_top_url: '%%BANNER_TOP_URL%%',
  banner_bottom_url: '%%BANNER_BOTTOM_URL%%'
});
```

Для подключения реферальных/трекинг-ссылок просто замените плейсхолдеры `%%...%%` на ваши URL (например, `https://...`). Если плейсхолдеры не заменены, сайт безопасно направляет пользователей на официальные страницы операторов.

## 📊 Аналитика и Метрики

В проект подключены готовые счетчики веб-аналитики с автоматическим отслеживанием целей и расширенным мониторингом:

- **Яндекс.Метрика**: включен Вебвизор 2.0, карта кликов, отслеживание ссылок и отказов.
- **Google Analytics 4 (gtag.js)**: отслеживание просмотров и событий взаимодействий.

### Настройка ID счетчиков:

В блоке `<head>` файла `index.html` замените плейсхолдеры на ваши реальные идентификаторы:

- `%%YANDEX_METRIKA_ID%%` — номер счетчика Яндекс.Метрики (например, `98765432`)
- `%%GOOGLE_ANALYTICS_ID%%` — идентификатор потока данных Google Analytics (например, `G-XXXXXXXXXX`)

### Настроенные цели и события (Goals / Events):

При кликах посетителей по целевым кнопкам перехода в БК автоматически отправляются события:
- `click_fonbet` (цель в Яндекс.Метрике / event в GA4) — клик по кнопке регистрации или ссылке Фонбета.
- `click_winline` (цель в Яндекс.Метрике / event в GA4) — клик по кнопке регистрации или ссылке Винлайна.
- `click_banner` (цель в Яндекс.Метрике / event в GA4) — клик по баннерам акций.
